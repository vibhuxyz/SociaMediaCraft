# Framing (Within the Frame) Guide

Goal
Direct focus and add context by placing the subject inside a secondary, environmental frame.

Theory
Using elements within the scene to create a "frame within a frame." This acts as a secondary boundary that traps the viewer's eye exactly where you want it.

Application in Filmmaking
- **Architectural Frames:** Doorways, windows, arches, tunnels.
- **Organic Frames:** Overhanging branches, a gap in a crowd of people.
- **Psychological Effect:** It can make a character feel trapped, observed (voyeuristic), or highly protected.
