# Voiceover Script Formatting Guide

Goal
Format the script so the AI voice model (and human reviewers) can perfectly understand the intended timing, emotion, and emphasis.

The Standard Formatting Rules

1. **ALL CAPS for Emphasis:**
   - If you want the voice to hit a word hard, capitalize it. 
   - *Example:* "You don't just want a car. You want a REVOLUTION."
2. **Ellipses for Natural Pauses:**
   - *Example:* "It’s not about the destination... it’s about the drive."
3. **Parentheticals for Direction:**
   - Place emotional direction in brackets before the line.
   - *Example:* [Soft, intimate] "Wake up to something better."
4. **Pronunciation Guides:**
   - If a word is tricky, provide the phonetic spelling in brackets immediately following the word.
   - *Example:* "Welcome to the new era of Açaí [ah-sigh-EE]."

Example Commercial VO Script Block
```text
[Upbeat, conversational]
Look... we all know Monday mornings are tough. 
[PAUSE 1s]
But what if they didn't HAVE to be?
Introducing the all-new BrewMaster 5000. 
[Fast, excited]
Faster. Hotter. Better.
```
