# Brand Colors Guide

Goal
Create a cohesive, recognizable visual identity through strict adherence to the brand's color palette.

Palette Structure
1. **Primary Colors:** The 1-2 core colors immediately associated with the brand (e.g., Tiffany Blue, Coca-Cola Red). These should be dominant in the hero shots.
2. **Secondary Colors:** Supporting colors used for accents, backgrounds, or to distinguish different product lines.
3. **Neutral Colors:** Whites, blacks, greys, or creams used for text, negative space, and balancing the design.

Implementation in Filmmaking
- **Production Design/Art Direction:** Integrate brand colors into the physical environment (wardrobe, props, set dressing).
- **Lighting:** Use colored gels or LEDs (motivated lighting) to cast subtle brand hues into the shadows or background.
- **Color Grading:** The final grade should shift the overall image toward the brand's aesthetic (e.g., warming up the image for a coffee brand, pushing cooler blue tones for a tech brand).

Prompting Instructions
- Explicitly pass HEX codes or standard color names (e.g., "Pantone 186 C", "Crimson Red") to image/video generation models.
- Specify how the color should appear: "A subtle crimson red accent on the character's scarf," or "Bathed in warm golden-yellow light."

Avoid
- Clashing colors that dilute the brand identity.
- Over-saturating the image to the point it looks unnatural (unless intentional).
- Using a competitor's signature color combination.
